# Write Attendance App

A lightweight, local-storage-based Student Attendance Management web application built for educational institutions.

## Features
- Institution Secure Login
- Real-time Date and Time display
- Add students with ID, Name, and Phone number
- Daily attendance tracking
- Auto-generate shortlist for students with below 75% attendance

## Tech Stack
- HTML5, CSS3, Vanilla JavaScript (No database required, uses LocalStorage)
